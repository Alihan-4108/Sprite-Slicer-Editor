Tools / SpriteSlicer — demo

What it does

Built for the parts of sprite slicing nobody enjoys doing by hand.

⚡

Batch slicing

Slice many sprite sheets at once instead of opening Unity's slicer one texture at a time.

🎮

Made for 2D games

Designed around the real Unity 2D workflow so your assets are ready to drop straight into the project.

🧩

Editor-native

Lives right inside the Unity editor under the Tools menu — no external apps, no extra setup.

How to open it

After adding the script to your Unity project, find the editor here:

▸ Tools → SpriteSlicer
